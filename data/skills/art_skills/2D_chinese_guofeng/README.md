# Guofeng 2D New Guochao Style Description

This style is specifically designed for the "Guofeng 2D New Guochao" theme. All art prompts, specifications, and generated content are strictly limited to:

- **Guofeng 2D Animation**: A 2D animation style set against the backdrop of traditional Chinese culture, covering themes such as xianxia, wuxia, and court intrigue
- **New Guochao Aesthetics**: A fusion of traditional Eastern elements with modern aesthetics, where classical charm coexists with a fashionable sensibility
- **Japanese Animation Rendering Techniques**: Modern Japanese animation coloring and lighting techniques, combining cel flat-shading with digital rendering
- **Eastern Ancient Charm**: Poetic atmosphere, negative space composition, and profound Eastern aesthetic expression
- **Delicate Brushwork**: Clear lines, intricate details, and refined character and scene design
- **Guofeng 2D Cinematic Quality**: Cinematic composition, layered lighting, dynamic tension, and emotional atmosphere

## Scope of Application

- AI art generation for Guofeng 2D themes (characters, scenes, props, storyboards, etc.)
- Visual creations requiring New Guochao aesthetics, Japanese animation rendering, and Guofeng ambiance
- Guofeng animation, game art, concept design, and illustration creation

## Strictly Prohibited Content

- Fully realistic photography / 3D realistic rendering
- Western fantasy / Gothic / Victorian styles
- Cyberpunk / Sci-fi / Excessively modern elements
- Rough lines / Blurry image quality / Low-precision modeling
- Chaotic colors / Inconsistent style / Aesthetic breakdown

## Style Experience

Under this style, you will experience:

- Characters with 2D proportions, exquisite ancient-style attire, and delicate, flowing lines
- Scenes filled with Eastern ambiance, rich traditional architectural details, and refined lighting rendering
- Meticulously crafted props and artifacts, clear material textures, and harmonious, unified colors
- Storyboards and rendering that emphasize cinematic quality, New Guochao aesthetics, and Japanese animation techniques

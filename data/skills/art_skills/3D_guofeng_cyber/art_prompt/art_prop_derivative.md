# Prop Derivative State Generation · Constraint Manual

---

## I. Derivation Principles

1. **Form Anchoring** — The core form/silhouette of the prop, core Chinese-style formal elements, and core cybernetic functional structures must remain clearly identifiable in all states. The fusion relationship between Chinese-style patterns and cybernetic structures must not be altered.
2. **State Readability** — State differences must be immediately obvious, allowing the audience to distinguish them instantly. State changes in Chinese-style elements and cybernetic functions must respond synchronously without logical conflicts.
3. **Narrative Service** — Each state variant serves a specific plot node within the Chinese-style cyberpunk worldview (e.g., awakening of ancient artifacts, functional modification, energy overload, spiritual energy depletion, etc.).
4. **Progressive Degradation** — Damage/aging/functional wear states must follow reasonable physical logic and cyberpunk worldview logic. Material changes must conform to the property rules of the corresponding materials.
5. **Pure Prop Independent Display** — Only the prop itself may appear in the frame. The appearance of any characters, hands, or limbs is strictly prohibited. The prop must not be in a state of being held, worn, gripped, or mounted. It must be presented independently as a still-life display, with no scene accessories.

| Item | Constraint |
|---|---|
| Background | Plain gray solid color #B8B8B8 (consistent with the design sheet), no extra textures or decorations, ensuring the Chinese-style cyber prop subject stands out |

## VI. Constraint Rules

### Mandatory

| ID | Rule |
|---|---|
| R1 | Prop core form/silhouette must be identifiable in all states |
| R2 | State changes must conform to physical logic |
| R3 | Must use 2x2 grid layout: Top-left front view + Top-right side view + Bottom-left back view + Bottom-right detail closeup |
| R4 | Must specify "plain gray solid background", even soft light, no hard shadows |
| R5 | Must preserve the unified fusion of Chinese core form, patterns, cultural elements, and cyber functional structures; the two must not be separated or misaligned in any state |
| R6 | Cyber functional structures, energy light effects, and rune effects must serve state expression; they must not obscure the prop's core form and state details |
| R7 | All newly added Chinese-style cyber-specific states must conform to worldview logic; material changes and state manifestations must correspond one-to-one |
| R8 | In all views of the 2x2 grid, the prop's Chinese core elements and cyber core structures must be fully presented, no cropping, no occlusion |

### Prohibited

| ID | Prohibition |
|---|---|
| X1 | Prop becomes unidentifiable after state change |
| X2 | Damage violating physical logic (e.g., jade rusting) |
| X3 | Excessive bloody/horror damage depiction |
| X4 | Appearance of any character image, including full body, half body, or partial (hands, fingers, arms, etc.) |
| X5 | Prop in a state of being held, gripped, worn, or in use |
| X6 | Appearance of elements implying the presence of a person (e.g., hand-held marks, wearing perspective, usage posture) |
| X7 | Strictly prohibited awkward splicing of Chinese elements and cyber structures, appearance of chaotic elements not conforming to the Chinese-style cyber worldview |
| X8 | Strictly prohibited excessive light effect overflow/overexposure, obscuring the prop's core form, patterns, and state details |
| X9 | Strictly prohibited state changes not conforming to Chinese-style cyber material logic (e.g., insect damage to spiritual energy crystal jade, paper-like tearing of composite metal) |
| X10 | Strictly prohibited modification of the fixed 2x2 grid layout, strictly prohibited cropping of the prop's core structures and patterns |
| X11 | Strictly prohibited adding any extra elements, textures, or scenes to the background; must maintain a plain gray solid background |

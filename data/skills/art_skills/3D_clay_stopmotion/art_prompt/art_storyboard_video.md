# Video Prompt · Visual Style Constraints

When generating video prompts, the following visual style tags must be injected:

| Mode | Style Tags |
|------|----------|
| **General Multi-Parameter Mode (English)** | `stop-motion claymation, clay texture, finger imprints, warm tones, soft bokeh, whimsical 3D cartoon` |
| **General First-Last Frame Mode (English)** | `stop-motion claymation, clay texture, finger imprints, warm tones, soft bokeh, whimsical 3D cartoon, shallow depth of field` |
| **Seedance 2.0 (Chinese)** | `Stop-motion claymation style, clay texture, finger indentations, warm tones, soft shallow depth of field, fantasy 3D cartoon` |
